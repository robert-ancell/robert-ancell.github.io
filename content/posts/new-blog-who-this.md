Hi, I'm Robert. I'm a software engineer who has been working in open source for a long time, these days mostly on Ubuntu and Flutter at Canonical. If you want the fuller version, there's an [about page](/about/) with more detail.

For years I wrote intermittently, at [Bob the Gnome](https://bobthegnome.blogspot.com), but it's been inactive for many years now. This is that blog's replacement. I've wanted to post more frequently than I have, for a long time. It's easy to let a thought pass by unrecorded because the older blog tools were a pain to use. I don't find it productive using social media so while this will likely have less reach it will hopefully still be useful.

This is where I'll be putting things down going forward: notes on Flutter, Ubuntu, open source development in general, and whatever else is in front of me at the time. Follow along if that sounds interesting to you!
